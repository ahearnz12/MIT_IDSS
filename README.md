# MIT IDSS Data Science Learning Collection

A comprehensive collection of **107 Jupyter notebooks** covering the complete data science curriculum from MIT's Institute for Data, Systems, and Society (IDSS). This repository contains hands-on tutorials, case studies, and practical implementations spanning foundational concepts through advanced applications.

## 📚 Learning Path Overview

### 🎯 Foundational Data Science (20+ notebooks)
- **Python Fundamentals**: Variables, data types, conditionals, loops, functions
- **Data Manipulation**: NumPy arrays, Pandas DataFrames, data cleaning workflows
- **Data Visualization**: Matplotlib/Seaborn with real automotive datasets
- **Exploratory Data Analysis**: Comprehensive univariate and bivariate analysis

### 📊 Statistical Analysis (15+ notebooks)
- **Inferential Statistics**: Hypothesis testing, t-tests, z-tests, confidence intervals
- **Statistical Methods**: One-tailed vs two-tailed tests, p-value interpretation
- **Real-world Applications**: Medical dose testing, challenge data analysis

### 🤖 Machine Learning - Core Algorithms (25+ notebooks)
- **Supervised Learning**: Linear/logistic regression, decision trees, ensemble methods
- **Unsupervised Learning**: K-means, hierarchical clustering, DBSCAN
- **Dimensionality Reduction**: PCA, t-SNE, spectral clustering, eigenvector analysis
- **Model Evaluation**: Cross-validation, grid search, performance metrics

### 🧠 Deep Learning & Neural Networks (8+ notebooks)
- **Convolutional Neural Networks**: MNIST, SVHN, Fashion-MNIST
- **Computer Vision**: Image classification, transfer learning
- **Neural Architectures**: Sequential models, layer design
- **Audio Processing**: Audio MNIST digit recognition

### 🚀 Advanced ML Applications (15+ notebooks)
- **Recommendation Systems**: Collaborative filtering, Million Songs dataset
- **Customer Analytics**: Personality segmentation, churn prediction
- **Financial Modeling**: Stock portfolio optimization, Kalman filters
- **Network Analysis**: Game of Thrones networks, social graph analysis

### 📡 Big Data Technologies (5+ notebooks)
- **Apache Spark**: Distributed SQL operations, bike-sharing analysis
- **Apache Hive**: Data warehousing, taxi trip analysis
- **Kafka Streaming**: Real-time Twitter data processing
- **Distributed Computing**: Large-scale data analysis patterns

## 🚀 Getting Started

### Prerequisites
- Python 3.8+ with Jupyter Lab/Notebook
- Core data science libraries
- TensorFlow/Keras for deep learning
- Apache Spark for big data notebooks

### Quick Start
1. Clone the repository
2. Install dependencies from root `requirements.txt`
3. Launch Jupyter: `jupyter lab`
4. Start with Practice Exercises for Python basics
5. Progress through the structured learning tracks
